## Sobre mim

Sou analista de dados e inteligência artificial na **UNIPAC · Grupo Jacto**, em Marília/SP, focado em manufatura inteligente. Desenvolvo agentes de IA e arquiteturas na Google Cloud que deixam o acesso à informação da fábrica mais ágil e intuitivo, da coleta de dados direto das máquinas até o painel que apoia a decisão.

- 🤖 Agentes e assistentes de IA para as áreas de Inovação Digital e Manutenção Industrial
- 🔌 Servidores MCP (Model Context Protocol) que ligam os sistemas da empresa a modelos de linguagem
- ☁️ Soluções na Google Cloud com Cloud Run e BigQuery
- 🏭 IA para manutenção preditiva e otimização de processos fabris

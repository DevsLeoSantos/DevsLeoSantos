## ⚡ Sobre mim

Sou analista de dados e inteligência artificial na **UNIPAC · Grupo Jacto**, em Marília/SP, focado em manufatura inteligente. Desenvolvo agentes de IA e arquiteturas na Google Cloud que deixam o acesso à informação da fábrica mais ágil e intuitivo, da coleta de dados direto das máquinas até o painel que apoia a decisão.

* 🤖 **Agentes e Assistentes de IA:** Soluções inteligentes para Inovação Digital e Manutenção Industrial.
* 🔌 **Servidores MCP:** Integração de Model Context Protocol conectando sistemas corporativos a LLMs.
* ☁️ **Google Cloud Platform:** Arquiteturas escaláveis utilizando Cloud Run e BigQuery.
* 🏭 **Indústria 4.0:** Conectividade de máquinas, dados em tempo real e manutenção preditiva.
